# تطبيق «ذِكْرى» — مساعد الذاكرة الشخصي الذكي (Dhikra AI)

تطبيق مساعد ذاكرة بالدارجة المغربية، مع فهرسة محلية للصور وتذكيرات مرتبطة بالذكريات.

## التشغيل

```bash
python3 server.py
```

ثم افتح `http://localhost:8080`.

## فهرسة Gallery محلياً

من تبويب **إضافة و OCR** يمكن للمستخدم اختيار صورة أو عدة صور بشكل صريح. التطبيق يعالج الملفات داخل المتصفح فقط، ويقرأ اسم الملف، نوعه، حجمه، أبعاده، تاريخ التعديل، وتاريخ EXIF في صور JPEG حين يكون متاحاً. كما يستعمل Tesseract.js لاستخراج النص العربي والإنجليزي من الصور التي تحتوي على كتابة، مع حدّ حجمي لتفادي استهلاك الذاكرة.

بعد التحليل، يقترح التطبيق علاش الصورة ممكن تكون مهمة اعتماداً على اسمها، النص المستخرج، والوصف الذي يكتبه المستخدم. يمكن كذلك اختيار تاريخ وتسجيل تذكير محلي للصور المفهرسة. البيانات الوصفية والتذكيرات كتتحفظ فـ `localStorage`، والصور ما كتترفعش إلى أي سيرفر.

> ملاحظة: نسخة الويب لا تستطيع قراءة Gallery كاملة تلقائياً بسبب صلاحيات المتصفح. خاص المستخدم يختار الصور يدوياً. فنسخة Android الأصلية يمكن ربط نفس المحرك مع MediaStore وWorkManager بإذن المستخدم.

## الملفات الأساسية

- `index.html`: الواجهة RTL وتجربة الهاتف وتبويب فهرسة Gallery.
- `gallery_engine.js`: قراءة metadata وEXIF، OCR محلي، تفسير أولي للغرض، التخزين والتذكيرات.
- `rag_engine.js`: محرك البحث المحلي وذكريات التجربة.
- `live_assistant.js`: مساعد الصوت والواجهة العائمة.
- `server.py`: سيرفر التطوير المحلي.
- `ARCHITECTURE.md`: التصور التقني لنسخة Android وMediaStore.
