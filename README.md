# تطبيق «ذِكْرى» — مساعد الذاكرة الشخصي الذكي (Dhikra AI)

تطبيق مساعد الذاكرة الذكي المخصص للدارجة المغربية، مستوحى من معمارية RAG المحلية وواجهات المساعد الصوتي المباشر لنظام أندرويد.

---

## 🚀 كيفاش تخدم التطبيق (Quick Start)

### الطريقة 1: بسيرفر بايثون (بأمر واحد)
افتح الـ Terminal ولا PowerShell ودخل لمجلد المشروع:
```bash
python server.py
```
غادي يفتح ليك المتصفح مباشرة على:
👉 **`http://localhost:8080`**

### الطريقة 2: مباشرة فالمتصفح
تقدر تكليكي جوج مرات (Double click) على ملف:
👉 **`index.html`** وغادي يخدم مباشرة بدون أي سيرفر أو إنترنت!

---

## 🌟 مميزات التطبيق

1. **واجهة أندرويد الحديثة (طِبق الأصل من الصور المرفقة)**:
   - تصميم OLED Dark Mode أنيق وجميل مع دعم كامل للعربية من اليمين لليسار (RTL).
   - شريط البحث التلقائي مع الكلمات المفتاحية بالدارجة.
   - تصنيفات سريعة (وصفة، حديث محفوظ، موعد الطبيب، صورة العيد).
   - بطاقة فيديو الطاجين مع المصدر وشارة "اقتراح" وشريط التقدم الأزرق.
2. **مساعد الصوت المباشر (Live Voice Assistant Overlay)**:
   - كبسولة "Partager l'écran avec Live" لمشاركة الشاشة.
   - تموجات صوتية حية (Audio Waveform) متحركة مع التكلم.
   - إمكانية المحادثة بالدارجة المغربية والحصول على الإجابة بالصوت والكتابة.
3. **محرك الاسترجاع الدلالي (Moroccan Darija RAG)**:
   - يفهم طبيعة الكلام اليومي بالدارجة ويستخرج الذكرى المناسبة مع المصدر.
4. **شاشة المعمارية التفاعلية**:
   - شرح خطوة بخطوة للـ 4 مراحل التقنية: جمع المحتوى، الفهرسة المحلية، استرجاع RAG، والتعلم الذاتي.
5. **محاكي الـ OCR واستخراج المتجهات**:
   - تجربة إضافة ذكريات جديدة واستخراج المتجهات وحفظها محلياً.
